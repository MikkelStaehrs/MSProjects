Quick entry
Ctrl K anywhere  ·  one field  ·  Enter saves

The feature that decides whether the tool survives past week three. One field. The prefix on the first character decides what gets written, and the same pure function parses the preview on the client and the record on the server, so the overlay can never promise one thing and save another.

No prefix  ·  a log entry
Chased IT again on the VLAN. Ticket reassigned, no date given.
Work entry on Data platform Tab changes target
Log entry Work ⌃1 Note ⌃2 Meeting ⌃3 Risk ⌃4 Enter saves

Work, Note, Meeting and Risk are kinds of log entry, not the four things quick entry can write. A prefix makes something else, and the row then dims and its shortcuts stop rather than sitting there looking like the control that decides.

The four prefixes
Chased IT again
Log entry on the target, with the chosen kind.
+ Write test protocol
New task under the target, status planned.
! Waiting for VLAN @ IT
Blocker on the target, waiting on IT. The last @ is read, so an email address in the title survives. The recipients already in use are offered as soon as the line starts with !, and the spelling is settled on the server, so «project board» is stored as «Project Board» and the chart never splits in two.
? Chose 130 kV // heavier seed needs it
Decision on the target. The rationale after // is optional.

The prefix counts only at the start of the line, so Load cells 4+2 mounted is an ordinary log entry.
